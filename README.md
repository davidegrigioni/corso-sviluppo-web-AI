# Corso di Sviluppo Web

Sto seguendo un corso per diventare sviluppatore web e qui pubblicherò i vari aggiornamenti del mio progetto.

In questa cartella troverai i progressi, le migliorie e le nuove versioni della mia app man mano che imparo e sperimento con HTML, CSS e JavaScript.

Acquisire competenze per creare pagine web dinamiche, funzionali e ben progettate, fino a diventare uno sviluppatore web completo.

## Aggiornamenti

Ogni modifica importante verrà mostrata qui per tenere traccia del percorso di apprendimento e dello sviluppo dell'applicazione.
